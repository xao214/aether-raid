# Aether Raid

Original neon vertical arcade shooter. Playable on phone and desktop.

## Run

Serve the folder (needed for the home-screen app and audio on some phones):

```bash
cd aether-raid
python3 -m http.server 8765
```

Open that URL on your phone (same Wi‑Fi) or in a desktop browser.

On iPhone: Safari → Share → Add to Home Screen.
On Android: Chrome → Add to Home screen.

## Controls

Phone
- Left stick to move
- Hold FIRE
- II pause · ♪ mute
- Tap the screen to start / restart

Keyboard
- WASD or arrows to move
- Space / Z / K fire
- P or Esc pause, M mute, Enter start
